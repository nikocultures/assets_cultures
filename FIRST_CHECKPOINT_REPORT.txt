DATAX / LIB FORMAT
Custom little-endian LIB. Header: three u32 words: retained header word (observed 1), directory count, file count. Directory rows: length-prefixed byte path followed by an unknown u32. File rows: length-prefixed logical path, absolute u32 data offset, u32 byte size. Payloads are raw ranges; no container compression flag or decompression. BMD payloads have their own RLE; CIF text is obfuscated.
Existing readers reused: cultures_lib.py/read_index and archive_blob from catalog_game_data.py. Production reference: MountedLibraryFile::loadDirectory, Game 0x0040665D; lookup 0x004068B3. Older Python directory field labels differ from the newer C++ interpretation, but consume the same bytes. Do not interpret the older 'alignment' label as proven semantics.

BMD FORMAT STATUS
Working production decodeBobLibraryBmd and drawing routines exist. No new BMD or archive parser was written. See Metadata\bmd_format.md.
The older Python PNG decoder treats kind 4's second byte as opacity and kind 2 as constant-alpha black. Those choices are not faithful for finished houses or native destination-dependent shadows. Sample export uses the C++ body draw routine, not those paths.

GAME.EXE HOUSE→ASSET CALL CHAIN
Game hash verified C52209CF06493142ECA1BA836AC3019943CAA003008EB998350354D0A9B8B85F.
0x0048E651 loads ordered GfxHouse records from houses.ini/CIF; record stride 0x8BC. The data associates LogicType[level], LogicTribeType, GfxBobLibs, GfxPalette, GfxBobId[level].
0x00430FCE creates a House with GfxHouse ID at +0x10 and extension level at +0x20; 0x0048089E retrieves the GfxHouse definition and selects logic type and tribe.
